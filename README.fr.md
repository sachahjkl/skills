# Skills

Skills personnels pour les agents de codage, partagés entre les projets et les clients d'agents.

## Skills inclus

- `francais-simple` : Rédiger des textes techniques clairs et précis en français.
- `nix-project` : Ajouter ou compléter le flake, les contrôles et les hooks de pré-commit d'un projet.

Chaque skill utilise `SKILL.md` comme point d'entrée. Les références associées restent dans le même répertoire.

## Installation

Exposez ce dépôt comme répertoire de skills pour agents, ou liez chaque skill dans `~/.agents/skills`.

Le dépôt `sachahjkl/nixconfig` installe chaque répertoire de premier niveau qui contient `SKILL.md`.
