# Skills

Personal coding-agent skills shared across projects and agent clients.

## Included Skills

- `francais-simple`: Write clear and precise technical French.
- `nix-project`: Add or complete a project flake, checks, and pre-commit hooks.

Each skill uses `SKILL.md` as its entrypoint. Supporting references stay in the same directory.

## Installation

Expose this repository as an agent skills directory, or link each skill into `~/.agents/skills`.

The `sachahjkl/nixconfig` repository installs every top-level directory that contains `SKILL.md`.
